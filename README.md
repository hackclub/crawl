# Crawl

a Hack Club You Ship, We Ship program: spend two or more hours building your own web crawler and get $10 toward a video game on Steam or Itch.io, or go for the big prize and spent 6 hours to get either Minecraft or a $30 video game (you pick!)


## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Preview the production build locally with `npm run preview`.

## Points of Interest

- `src/App.vue`: all page content and styles.
- `src/assets/`: artwork.
- `index.html`: meta tags, favicons, and fonts.
- `public/`: favicons.
